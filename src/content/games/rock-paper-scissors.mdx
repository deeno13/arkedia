Rock Paper Scissors is a useful early example because the rules are tiny, the outcomes are easy to compare, and an interactive demo can stay extremely small.

## What this page demonstrates

This page uses MDX for the explanation and frontmatter for metadata. The playable widget is not embedded directly into the prose. Instead, the page template reads the frontmatter and mounts a matching island only on pages that need one.

## Teaching ideas

- talk about the difference between random outcomes and predictable rules
- ask learners to track how often each result appears over several rounds
- connect the game to probability vocabulary such as win, lose, draw, and sample size

## Guardrail

If a game page can teach well through content alone, keep it static. A widget should be added because it improves understanding, not because interactivity is available.
